ML Model Selection

Select the active ML model for plant identification. The model must be available in the ML service.

ML Confidence Thresholds

Configure confidence thresholds per model. Off = no gating, Log = record verdict only, Enforce = gate results.

Discovery Settings

Configure caps and timeouts for the discovery report loop.

Description Votes

Thumbs up / down on contributor descriptions. Every signed-in user can vote, with no limit. Lowering the hide number hides descriptions that already have that many downvotes.

Plant Photos

How many photos one contributor submission may carry (applies to new plants and to contributions, from the next upload), and how many photos the admin plant editor loads per page.

ML Request Settings

Configure limits for ML inference requests.

Spam Quotas (Per-Role)

Per-role limits. Press Save to apply edits; an empty box uses the default.

Dataset Audit

The model that compares photos in the Dataset audit and the Other plant tab, and how alike two photos must be to be flagged. These are the same values as the quick row on the Dataset page. A change applies from the next audit.
