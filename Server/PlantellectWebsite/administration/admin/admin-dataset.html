      Database photos and snapshots

      Approved photos that an admin marked Included (in the Edit dialog of each plant, under Photos) can be written to a database snapshot: a new folder with the photos, a manifest and the groups. The split script reads it with --snapshot <name>. Hiding a photo does not remove it from a snapshot; archiving one does. Nothing here changes a photo.

      Scan contributions are private training photos that users offered after a very confident scan. They are never public and start as Candidate, like every other photo: they only reach a snapshot once an admin marks them Included (in the Edit dialog of the plant, under Photos), and an admin can archive one there to take it out of use.
